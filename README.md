# Task Manager

## Overview
This project is a localized Task Manager built from scratch. Its primary purpose is to serve as a practical learning environment for mastering **Standard React Architecture** without relying on framework "magic" like Next.js. 

The focus of this project is to understand:
* Client-side manual routing using `react-router-dom`.
* Component lifecycle and state management.
* Strict typing for data models using TypeScript.
* Modern build pipelines using Vite and Tailwind CSS v4.

## Tech Stack
* **Frontend UI:** React 19
* **Language:** TypeScript
* **Bundler/Build Tool:** Vite
* **Styling:** Tailwind CSS v4
* **Routing:** React Router DOM v7
